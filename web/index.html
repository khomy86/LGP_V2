    How it works

    1. Find the handMediaPipe's hand landmarker returns 21 3D points for the hand in each video frame.
    2. NormalisePoints are made relative to the wrist and scaled by hand size, so position and distance to the camera don't matter.
    3. ClassifyA 17k-parameter neural network scores each frame. The same model ships as TensorFlow Lite in the Android app.
    4. SmoothThe last 10 frames are averaged, and a sign is shown only above 60% confidence.

    Recognises static hand shapes only. Signs that differ only in movement are out of scope. Trained on a small dataset recorded by a few people, so results vary with lighting and hands.
